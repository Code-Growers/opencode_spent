# openspent_core

`openspent_core` is the shared pure Dart package for OpenSpent. It is intended to hold reusable domain models, repositories, parsers, and business logic that should remain independent from Flutter UI concerns.

## Build

This package is a library, so there is no standalone build output in the current scaffold.

## Analyze

```bash
dart analyze .
```

## Test

```bash
dart test
```
